# Premium Settings v8 — Ta7ady ElGeel

**النسخة الأساسية:** Live Stage Lighting v7. هذه النسخة تستبدل *تصميم نافذة الإعدادات فقط*، وتحافظ على بنية المسرح وTwitch والميني جيمز ونظام النقاط.

## التصميم

- نافذة Desktop Control Room بعرض يصل إلى 930px، ومحتوى عمودين وFooter ثابت للأوامر.
- خمس مجموعات واضحة: حساب Twitch، الصوت، وضع العرض، اللغة، الدقة.
- تجنب ازدحام الحواف والنصوص المتوهجة؛ استخدام الأزرق السماوي للتحديد، والوردي للأفعال الخطرة.
- فصل الاتصال بـTwitch ما زال يستدعي نافذة تأكيد قبل التنفيذ.
- الدقة غير متاحة إلا إذا جرى اختيار وضع Windowed؛ في باقي الأوضاع يظهر تفسير للحالة بدلاً من إخفاء إعداد الدقة.
- اللغة العربية RTL مدعومة، مع إبقاء كتابة قيم دقة الشاشة باتجاه LTR.
- زر تطبيق التعديلات لا يُفعّل إلا إذا كانت هناك تعديلات معلّقة؛ حالة التغييرات تظهر في أسفل النافذة.
- التحكم في الصوت يحافظ على نظام حفظ الصوت الحالي ولا يحفظ قبل Apply.
- دعم Esc / Tab / استعادة التركيز / Reduced Motion.

## إصلاح حالة دقيقة

الكود السابق كان يراقب `savedDisplaySettings` و`audioTuning.globalVolume` أثناء فتح النافذة، مما قد يعيد ضبط اختيارات المستخدم غير المحفوظة. تم إزالة أثر إعادة الضبط مع جعل قراءة إعدادات الشاشة والاشتراك في التحديثات تتم عند mount بدلاً من كل فتح.

## الملفات المعدلة

- `src/ui-react/components/settings/AppSettingsButton.tsx` — إعادة بناء UI والحفاظ على Actions.
- `src/ui-react/styles/premium-settings-v8.css` — Style مستقل يستهدف نافذة الإعدادات، بدون تغيير الـCSS القديم.
- `src/ui-react/main.tsx` — استيراد ملف التنسيق الجديد بعد أنماط اللعبة السابقة.
- `scripts/verify-premium-settings.mjs` — فحص بنيوي لتفادي سقوط وظائف مهمة.
- `package.json` — أمر `npm run verify:premium-settings`.

## التحقق

تم تشغيل فحوص الـcleanup والـlighting والأمان (24/24)، وتحليل صياغة TSX وCSS، واختبار **معاينة HTML/CSS** مع كامل طبقات الـLegacy CSS على 1280×720 و1650×928 و1920×1080، ومعاينة RTL على 1280×720 و1650×928. هذه محاكاة لواجهة النافذة وليست صورة من تشغيل تطبيق Electron نفسه.

**لم يتم تشغيل Build/Typecheck كامل داخل بيئة العمل بسبب نقص حزم المشروع المثبتة.** يرجى تشغيل `npm install` ثم `npm run build` وفتح اللعبة في Windows، والتحقق من تغيير الدقة وإغلاق/إعادة فتح النافذة وقراءة Twitch عبر التطبيق.

## خطة تجربة سريعة داخل Windows

1. افتح Settings، غيّر الصوت واللغة، ثم Cancel، وأعد فتحها للتأكد من عدم حفظ الاختيارات.
2. غيّر وضع العرض إلى Windowed، ثم غيّر الدقة، ثم Apply، وتأكد من تطبيق الاختيارات واستمرارها بعد إعادة الفتح.
3. اختبر التبويب Tab وShift+Tab وEsc.
4. افتح تأكيد فصل Twitch، ثم اختر Cancel للتأكد أن الاتصال لم يُقطع.
5. اختبر العربية على 1280×720 مع طول أسماء Twitch.
6. جرّب الإعدادات أثناء جولة لتتأكد من ظهور End Session وعمله كالمعتاد.
