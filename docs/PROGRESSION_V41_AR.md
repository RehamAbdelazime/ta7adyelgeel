# Ta7ady ElGeel — V41: XP at the finish line

## ما تغيّر
- فصلنا **نقاط ترتيب الـTour** عن **XP الدائم**.
- أثناء الأسئلة تظهر نقاط المنافسة فقط. لا يتم تعديل `profile.xp` ولا المستوى، ولا يظهر أي Level Up في هذه المرحلة.
- يُجمَّع XP المكتسب مؤقتًا حسب رقم الجولة، ثم يُضاف **مرة واحدة فقط** عند الدخول إلى `tour_complete`، سواء كانت جلسة `Full Tour` أو `Single MiniGame`، حتى لو اختتمها الهوست مبكرًا.
- الـFinal Scoreboard فقط يعرض `+XP` و`Lv.`، ويبرز الترقية `LEVEL UP` لو حصلت. لا يظهر XP للـSpectators، ولا يغيّر نتائج المنافسة.
- إزالة Coins بالكامل من نظام البروفايل والـRuntime Config والتقدم، مع قراءة البروفايلات القديمة بدون تصفير XP أو المستوى. البيانات القديمة التي تحتوي على Coins تُقبل ثم تُحفظ بدون حقل Coins.
- الـFeed التشخيصية ما زالت موجودة داخليًا لكنها ليست عرضًا مرئيًا للاعب على المسرح. التقدم المرئي أصبح داخل النتيجة النهائية.

## نظام XP المنفصل

| المكافأة | XP |
|---|---:|
| إكمال جلسة Single MiniGame بإجابة واحدة على الأقل | +10 مرة واحدة |
| إكمال Full Tour بإجابة واحدة على الأقل | +20 مرة واحدة |
| إجابة صحيحة Easy | +8 |
| إجابة صحيحة Medium | +12 |
| إجابة صحيحة Hard | +16 |
| إجابة جزئية غير صفرية | +4 |
| إجابة خاطئة | +0 (مع استحقاق مكافأة المشاركة عند النهاية) |
| أول / ثاني / ثالث في Full Tour بشرط السكور الموجب والمشاركة | +15 / +8 / +4 |
| أول / ثاني / ثالث في Single MiniGame بشرط السكور الموجب والمشاركة | +8 / +4 / +2 |

- الـChaos يغيّر **نقاط المنافسة** فقط، ولا يضاعف XP.
- لا يتم منح XP لمن لم يجاوب، ولو كتب `!join` فقط. الـSpectators يشاركون في النقاط والترتيب الخاص بهم لكن لا يتلقون XP.
- انتهى التمويل اليومي للعملات؛ لا يوجد Wallet ولا Shop ولا Coins في البيانات الجديدة.
- تم الإبقاء على منحنى المستويات القديم المكوّن من 20 مستوى للحفاظ على مستوى ومجهود اللاعبين المسجلين.
