# V44 — صور حقيقية + QA Bots (README)

## الصور: لا يوجد أي تصميم مرسوم بديل للصور الفعلية
- حذفنا **كل 30 رسمة SVG المصطنعة** الخاصة بأسئلة الأفلام من المشروع.
- أضفنا **16 مرجعًا لصور فعلية** مرتبطة بأفلام موجودة في البنك (مشاهد/بوسترات) من صفحات ومعارض صور أصلية؛ **لا توجد أي موافقة توزيع/بث مؤكدة لتلك الصور**. الروابط مجرد ترشيحات لاستخدامها بعد أخذ الحق، وقد تمنع المصادر عرضها المباشر أو تغير روابطها. لا يتم تضمين ملفات الأفلام المحمية في ZIP.
- الـ30 سؤالًا ما زالت موجودة للتجهيز؛ **14 منها ناقصة صورة حقيقية** ولذلك لا تدخل سحب اللعب حاليًا. يكفي الآن 16 سؤالًا للاختبار فقط؛ بعد توريد صور مصرح بها يمكن تفعيل الباقي. اختيار الأربع أسئلة يتم من صور متوفرة حسب Easy/Medium/Hard/Hard، وScene/Poster بالتناوب.
- صور النجوم **20 صورة فوتوغرافية حقيقية من Wikimedia Commons** بتراخيصها المسجلة لكل صورة، لكنها غير مضمنة في ZIP لأن التحميل الخارجي لم ينجح في بيئة التوليد. يرجى مراجعة كل مصدر وشروط النسب لأي تعديل وقبل إعادة التوزيع، خصوصًا إذا كان الترخيص ShareAlike. يحمّلها أمر `npm run visuals:cache` (إن توفر الإنترنت).
- **عيون المشاهير** الآن تُعرض من *الصورة الفوتوغرافية نفسها* داخل نافذة مقصوصة بالـCSS، مع إخفاء بقية الوجه أثناء السؤال. لا يتم اصطناع أي عيون أو وجوه. يجب مراجعة focal point لكل صورة بصريًا لتظهر العينان بدقة؛ ملفات الصور الأصلية تظهر عند الكشف.
- بوسترات الأفلام يتم إخفاء منطقة عنوانها تقديريًا بـtitleMask؛ راجع كل بوستر بعد الاستيراد. إذا ظل اسم الفيلم مكشوفًا صحّح إحداثيات القناع في JSON.

**حقوق الصور:** رخصة الصورة العامة، إذا وجدت، ليست ترخيصًا تلقائيًا لمشهد/بوستر فيلم آخر. لا تفترضي أن صور elCinema وIMDb وTMDb وغيرها مصرح ببثها أو إعادة توزيعها لمجرد أن رابطها متاح. يجب موافقة صاحب الحق، أو أساس قانوني مناسب يراجعه صاحب المشروع.

### تجهيز الصور على جهازك
1. من مجلد المشروع بعد فك ZIP، شغّلي `npm run visuals:status` لمعرفة الملف المتاح محليًا والناقص.
2. على جهاز متصل بالإنترنت: `npm run visuals:cache` لتحميل صور Commons الخاصة بالنجوم فقط.
3. لكل فيلم لديك إذن استخدام صورة حقيقية له: `npm run visuals:import -- movie-el-nazer "D:/Media/real-scene.jpg" "صاحب الصورة" "مرجع الإذن/الترخيص"`.
4. الصور بعد الاستيراد تحفظ تحت `public/assets/game/runtime/minigames/visual-guess/` بنفس اسم السؤال وتظهر دون إنترنت. لا يعيد النظام تصنيع أي بديل.
5. راجعي `docs/V44_REAL_PHOTO_SOURCES_AND_RIGHTS.csv` لتتبعي الصور غير المرخصة أو المفقودة.

## بوتات الاختبار
من `Host Panel → QA`:
- `+5 / +25 / +100 / +300 bots` أو `Custom bots` بعدد تختاريه لإضافة دفعات صغيرة وكبيرة، بحد أقصى 500 في الجلسة.
- `▶ Auto answer every question` لتسجيل إجابات تلقائية **عبر نفس Twitch command router الحقيقي**، ويظل شغالًا حتى بعد قفل لوحة QA. زر `Stop auto answering` لإيقافه.
- اختيار `Mixed / Random / All !1` للتحكم بسلوك الإجابات.
- `Answer now` يرد بالبوتات في السؤال المفتوح حاليًا.
- `Remove QA bots` يحذف **البوتات وحدها** بعد نهاية التور، بدون حذف المشاهدين الحقيقيين.
- المضافون قبل أول سؤال Official، وبعده Spectators. يمكن تجربة الـScoreboard وChaos وXP وPause وFull Tour على أي حجم متاح.
- الـQA bots **لا تُصدَّر إلى profiles.json** ولا يُحفظ سجل الجولة التي يدخلون فيها في تاريخ التورات. أسماؤهم تبدأ BOT_، ومعرّفاتهم مشروطة ببادئة خاصة.

## تحقق
- `npm run verify:media-qa-v44`
- `npm run verify:all`
- `npm run visuals:status`  (يعدّ صور المصدر والناقص؛ يرجع كودًا غير صفريًا إذا كانت هناك صور ناقصة، وهو متوقع حتى تتم مراجعة الحقوق).

**قيود واضحة:** اختبار واجهة Electron على Windows لم ينفّذ هنا (مكتبات npm غير مثبتة)، ولا نستطيع التأكيد أن جميع روابط الصور ستعمل أو أن قص العيون مضبوط تمامًا لكل شخص قبل مراجعة الصور المحملة.

## أمان الاختبار وتغطية الأداء
- دفعات 500 بوت اختُبرت على نفس GameStore؛ 72 شخصية فقط تظهر في المسرح والباقي يشارك في النتائج.
- أزرار QA القديمة للإجابات تستهدف هوية الاختبار فقط، ولا ترسل إجابات باسم مشاهدي Twitch الحقيقيين.
- الـPause يوقف الـAuto Answer، وعند Resume نفس السؤال يُعاد جدولة إجاباته بشكل صحيح.
- زر Stop Auto يوقف الإجابات فقط دون قطع دفعة انضمام بوتات لم تكتمل.
