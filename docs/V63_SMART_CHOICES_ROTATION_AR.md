# V63 — اختيار الإجابات المتجدد لأسئلة القفشات

**المبني عليها:** V62 QUOTE FAIR GAMEPLAY. التغيير خاص بأسئلة **«كمّل الجملة» و«مين قالها؟»** في Guess the Movie. لم تُحذف أو تُعدل أي صورة في `Posters` أو `Frame`، ولا ملف واحد من محتوى `Quotes` الذي أضافه المستخدم.

## المشكلة
في V62 كان كل ملف جملة بيحتوي على إجابة صح + **ثلاث إجابات غلط بالضبط**. الأرقام 1–4 كانت بتتبدّل، لكن المحتوى الفعلي للاختيارات الغلط هو نفسه كل مرة، وبالتالي سؤال الجملة بعد التكرار بيتحفظ بدون تحدّي.

## الحل
- دلوقتي بقى فيه **بنك بدائل غلط** لكل واحدة من الـ14 تكملة القابلة للعب: 3 اختيارات أصلية + **5 نهايات بديلة مؤلّفة** مناسبة لسياق الجملة. اللعبة بتسحب 3 في كل ظهور.
- «مين قالها؟» بيستخدم نفس الـ3 ممثلين الأصليين ومعاهم مجموعة ممثلين إضافيين من **نفس الفترة/النوع الفني**، مش أشخاص عشوائيين من كل السينما. الممثلون البديلون في القوائم **اختيارات خاطئة فقط** وليس ادّعاء بأنهم أصحاب القفشات. لشخصيات الأفلام مجموعة ألقاب تخمينية منفصلة بدل أسماء الممثلين.
- الاختيار فيه دائمًا **1–2 من البدائل الأصلية** والباقي من المجموعة الإضافية، مع مراعاة الصعوبة: Hard أقرب للمجموعات الأصلية، وEasy أكثر تنوعًا.
- فيه **History** محفوظة محليًا لمجموعات الإجابات السابقة لكل سؤال، فتتجنّب اللعبة تكرار نفس التلاتة غلط المتجاورين قدر الإمكان، **حتى بعد قفل Electron وفتحه**. لو المجموعة صغيرة جدًا، التكرار وارد؛ مش بنخترع إجابات عشوائية عشان نخفيه.
- موضع الإجابة الصح (1–4) بيتغيّر كمان، وبيتجنّب نفس المكان في السؤال المكرر التالي.
- الإجابة الصحيحة نفسها **مابتتغيّرش**، وتفضل مخفية لحد كشف الإجابة يدويًا. نظام النقاط وتسجيل إجابات الهوست والمشاهدين لم يتغير.
- «مين قالها؟» و«كمّل الجملة» الجملة كاملة من البداية (تصحيح V62 محفوظ). أما «الجملة دي من فيلم إيه؟» لسه بالكشف التدريجي.

## مثال توضيحي: «كمّل الجملة»
- بداية الجملة: «كابتن، هو كله ضرب ضرب»
- الإجابة الصحيحة: «مفيش شتيمة؟»
- المجموعات الغلط بتتبدل بين نهايات زي «مفيش إنذار؟»، «هو إحنا في ماتش؟»، «فين الحكم يا كابتن؟»، «مفيش حتى استراحة؟»... إلخ.
- كل مرة بيظهر **3 غلط فقط** مع الإجابة الصح، مش القائمة الطويلة كلها.

## لما تزود جمل جديدة بنفسك
كل سؤال جديد لسه يقبل نفس تنسيق JSON في `Quotes`. حقل `wrong` بقى يقبل **من 3 إلى 24 اختيارًا مختلفًا** بدل بالظبط 3، سواء في `completion.wrong` أو `speaker.wrong`. اللعبة تختار 3 مختلفين مع منع تكرار الإجابة الصح. النهايات في أسئلة `completion` لازم تكون عبارات من كلمتين على الأقل، وبداية الجملة من 4 كلمات على الأقل، علشان السؤال يبقى عادل.

**مثال بيانات غير منسوبة لأي فيلم حقيقي (لشرح الفورمات فقط):**
```json
{
  "ar": "لو الناس كلها اتأخرت أنا هقول إيه؟",
  "completion": {
    "prompt": "لو الناس كلها اتأخرت",
    "answer": "أنا همشي لوحدي",
    "wrong": [
      "هشوف بكرة إيه اللي حصل",
      "هنستنى شوية كمان",
      "هطلب تاكسي وأمشي",
      "هفتح موضوع تاني",
      "هكلمهم على التليفون",
      "هروح أتغدى بدري"
    ]
  }
}
```
البدائل الإضافية للـ40 جملة الحالية محفوظة في `src/game-core/minigames/visual-guess/quote-choice-pools-v63.json` منفصلًا عن ملفات المستخدم الأصلية. تكملات هذه القائمة تتطبق فقط لما رقم الجملة والإجابة الصحيحة يتطابقوا؛ تعديل نص الإجابة في ملفك يعطّل البدائل القديمة تلقائيًا. تقدر تكتب مجموعات أكبر بنفسك داخل `wrong` للجمل الجديدة.

## طريقة تطبيق Patch V63 على V62
1. **لا** تفك ملف المشروع الكامل فوق مشروعك الحالي. استخدم Patch فقط فوق **نسخة V62**.
2. فك `ta7adyelgeel_v63_SMART_CHOICES_PATCH_V62.zip` بجانب `package.json` في جذر المشروع. هتظهر أداة `APPLY_V63_PATCH.mjs` وفولدر `.v63_payload`.
3. شغّل `node APPLY_V63_PATCH.mjs`. الأداة بتفحص بصمة الملفات الأربعة اللي هتتغير **قبل تعديل أي ملف**، وترفض لو نسختك مش V62 مطابقة. وبتعمل Backup للكود المتغير في `.v63_code_backups`، مش للصور.
4. شغّل `npm run visuals:sync` ثم `npm run verify:quote-variety-v63` ثم `npm run dev`.
