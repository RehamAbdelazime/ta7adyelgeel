# V76 — عدّ الإيقاع: مراجعة قابلية اللعب

- الخلل: Easy كان 8–12 رمزًا مطلوبًا + 14–18 مشتتًا بمعدل 108 BPM، وHard كان يصل إلى 15–22 مطلوبًا + 28–37 مشتتًا بمعدل 158 BPM؛ مع رموز متزامنة، ألوان وأحجام غير موحّدة.
- الآن: 10–12 رمزًا إجماليًا في Easy (54 BPM)، 12–14 في Medium (60 BPM)، و14–16 في Hard (66 BPM). رمز واحد في كل ضربة، من غير تداخل.
- جميع الرموز داخل الجولة بنفس اللون والحجم والإضاءة والاتجاه، سواء الرمز المطلوب أو المشتّت. الاختلاف في شكل الرمز فقط.
- المعروض كبير ومتمركز في جزء محدود من المسرح، ولا تتغير الألوان.
- أُصلحت إعادة ضبط CSS animationDelay مع تحديث المؤقت. الوقف والاستكمال يتعاملان مع animationPlayState.
- زمن الإجابات للعبة دي فقط 26 ثانية. تسلسل الرموز ينتهي قبل 15.5 ثانية، فيتبقى **أكثر من 10 ثوانٍ** للشات.
- بعد نهاية الرموز تظهر عبارة صغيرة «دلوقتي جاوب في الشات»؛ لا تعرض العدد قبل كشف الهوست.
- الصوت: نبضة موحدة لكل رمز، من غير نغمة مختلفة للرمز المطلوب.
- صفحة «طريقة اللعب» اتعدلت لتُظهر رمزًا واحدًا بدلاً من عرض 7 رموز متجاورة بألوان مختلفة.
- قواعد الإجابة `!العدد` ونظام النقاط وكشف الهوست لم تتغير.
- اختبارات: `node scripts/verify-count-the-beat-playability-v76.cjs`، `npm run verify:quality-v38`، `npm run verify:all`.
- المراجعة البصرية النهائية تحتاج تجربة فعلية داخل Electron مع 720p/1080p، وصوت Twitch الفعلي.
