# V77 — عدّ الإيقاع: العرض أولًا، وقت الإجابة بعده

- مرحلة `tour_starting` غير قابلة للإجابة: كل الرموز تظهر وتختفي بالترتيب (رمز واحد في كل مرة، لون موحّد).
- مدة المرحلة محسوبة تلقائيًا بدقة من عدد النبضات وسرعتها؛ آخر رمز يختفي ثم توجد مهلة انتقال 280ms فقط.
- بعدها فقط ينتقل Tour State Machine إلى `answer_window_open` ويبدأ المؤقت المعتاد 20 ثانية **من البداية**.
- أثناء الإجابة تختفي الرموز وتظهر رسالة بارزة «دلوقتي تقدر تجاوب!» و«اكتب ! وبعدها العدد في الشات».
- Twitch وإجابة الهوست مقفولين في مرحلة العرض؛ فتحهما محصور بمرحلة الإجابة. التوقيف/الاستئناف يوقف تسلسل الرموز ويحفظ المدة المتبقية.
- صفحة «طريقة اللعب» الثانية تعرض رسالة الإجابة الجديدة، مش الإجابة الصحيحة.
- لا تغييرات في بقية الألعاب أو الصور أو قواعد النقاط.
- لتطبيق التحديث: فك محتويات ZIP في جذر مشروع V76 بجوار package.json واستبدل الملفات. **لا توجد سكريبتات APPLY.**
- تحقق: `node scripts/verify-count-the-beat-playability-v76.cjs` ثم `npm run typecheck` ثم `npm run dev`.
