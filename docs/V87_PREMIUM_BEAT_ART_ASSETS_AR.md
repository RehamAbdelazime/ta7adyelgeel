# V87 — صور Count the Beat الجديدة

مبني على Full Canonical Source V86 مباشرةً مع الحفاظ على منطق التحديات والنتائج والـChaos دون تغيير.

## التعديلات
- سبعة ملفات PNG من الصور الأصلية التي أرسلتها المستخدمة، بما فيها أسطوانة الموسيقى السابعة.
- كل الملفات 512×512 بحدود شفافة ومساحة أمان قرابة 8%؛ القصّ من مناطق الشفافية فقط، دون إعادة رسم أو تغيير ألوان أو إطارات العناصر.
- مكوّن `BeatIcon.tsx` المشترك يستخدم نفس الصور في هدف السؤال، ظهور الرموز، الكشف، وشرح اللعب.
- استخدام `import.meta.env.BASE_URL` مهم للـElectron بنظام file://.
- تجهيز الصور السبعة مسبقًا عند تحميل المكوّن يمنع تأخر ظهورها في التسلسل المتسارع، مع الاحتفاظ بملفات PNG نفسها أثناء اللعب.
- لم تتغير خوارزمية الأسئلة أو ترتيب الراندوم أو 1/2/4 سطور أو صوت الإيقاع أو مؤقت الإجابة المنفصل.

## الاختبار
- `NODE_PATH=$(npm root -g) node scripts/verify-beat-premium-icons-v87.cjs`
- `NODE_PATH=$(npm root -g) node scripts/verify-count-the-beat-v86.cjs`
- `NODE_PATH=$(npm root -g) node scripts/verify-count-the-beat-playability-v76.cjs`
- افتحي اللعبة في Electron عندك لاختبار الصورة الفعلية على المسرح؛ لم يتم إجراء Windows Build في هذه البيئة.

## الاستخدام
فكّي ZIP التعديلات من جذر مشروع V86 فوق `package.json`، واختاري Replace. لا يوجد أي `APPLY.mjs`.
