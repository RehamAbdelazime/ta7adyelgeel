# V90 — RTL اختيار الإجابات وإزالة عداد زائد

- أساس التعديل: آخر Source V89. ينطبق على جميع الشاشات التي تستخدم `QuestionScreenShell` المشترك.
- ترتيب الإجابات بالعربي: `!1` على اليمين ثم `!2` ثم `!3` ... على اليسار. بالإنجليزي: `!1` على الشمال كالسابق.
- شارة رقم الاختيار داخل الكارد بتتحرك لنفس الناحية؛ نص `!1` يبقى `dir=ltr` عشان الأرقام وعلامة التعجب ما تتقلبش.
- عداد إجابات كل اختيار **تحت الرمز** بيظل موجودًا؛ اتشال الإجمالي المكرر أسفل الصف، ومساحته لا تُحجز للشاشات الحديثة.
- مصابيح/ممرات الإجابات على المسرح بتتبع ترتيب RTL؛ تحركات الجمهور إلى اختيار `!1` تذهب فعليًا لممر اليمين في العربي، وليس لممر الشمال.
- الميني جيمز نفسها (مسار الليزر، الكوبايات، حساب الأسئلة، نقاط السكور، التوقيت) بدون أي تغيير.
- ضبط الواجهة مش متكرر: CSS موحّد مستورد آخر الملف، ومكوّنات `ChoiceCard` و`ChoiceSpotlights` باقية.
- فحوصات: `node scripts/verify-answer-choice-rtl-v90.cjs` و`node scripts/verify-answer-lanes-v20.mjs` و`npm run qa:unit`.
