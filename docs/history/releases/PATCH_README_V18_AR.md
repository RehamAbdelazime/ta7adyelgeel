# طريقة تثبيت Question Stage v18

الـPatch مخصص لنسخة **Question Experience v17** فقط؛ لا تطبقيه فوق v16 أو v15 مباشرة.

1. خذي نسخة احتياطية من ملفات مشروعك الحالي.
2. انقلي ملفات ZIP داخل جذر المشروع مع الحفاظ على المجلدات؛ وافقي على الاستبدال.
3. في Terminal بالمشروع: `npm install` ثم `npm run verify:question-stage` ثم `npm run build`.
4. جرّبي Food Origin ثم Maze Gates، قبل الإجابة وبعد كشفها، وبالعربي والإنجليزي.
5. لو تفضّلي عدم دمج الملفات يدويًا استخدمي SOURCE v18 كاملة في مجلد منفصل.

لم يتم حذف أو نقل أي ملف موجود في v17. ملفات CSS/TSX الجديدة والمعدلة فقط.
