# PATCH v20 — سؤال Game Show + Answer Lanes

**يُطبّق هذا Patch فوق النسخة الكاملة v19 فقط**: `ta7adyelgeel_question_scoreboard_v19_SOURCE.zip`.

## التركيب
1. خُذ نسخة احتياطية أو افتح مشروع v19 في مجلد جديد.
2. انسخ محتويات ZIP إلى **جذر المشروع** مع استبدال الملفات المتطابقة. حافظ على بنية `src/` و`scripts/`.
3. افتح Terminal في الجذر وشغّل `npm install` إن كانت تبعيات Vite غير مثبّتة.
4. نفّذ `npm run verify:question-zones` ثم `npm run build` ثم جرّب اللعبة: `npm run dev`.

## النطاق
توزيع السؤال الأفقي الجديد لـFood Origin وMaze Gates، مع أربع حارات طولية للجمهور عبر نظام الأرضية المشترك، وظهور إجابة الهوست فوق رأسه. **لا تغيير على الـScoreboard أو قواعد النقاط.**

**تنبيه:** المعاينات HTML/CSS محاكاة وليست تنفيذًا مصدقًا داخل Electron. الاختبار العملي مع Twitch وجمهور كبير ما زال لازمًا. كما أن حقل الهوست قد يظهر على OBS رغم إخفاء الرقم داخل Password input.
