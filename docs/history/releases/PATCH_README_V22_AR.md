# PATCH — Event Lighting v22

الـPatch ده مخصص فقط لنسخة **ta7adyelgeel_scoreboard_lighting_v21_SOURCE.zip** أو مشروع مُحدَّث سابقًا بتعديلات v21.

1. خدي نسخة احتياطية من المشروع.
2. فكّي ملفات الـPatch على **جذر مشروع v21**، مع استبدال الملفات المعدلة.
3. لا تحذفي أي ملفات؛ هذا التحديث لا يحتاج حذفًا.
4. شغّلي `npm run verify:event-lighting` ثم `npm run build` عندك بعد تثبيت dependencies الموجودة بالفعل.

التغيير مرتبط بمراحل الكشف والنتائج فقط، ولم يمس منطق احتساب النقاط أو استقبال Twitch أو طريقة اختيار الإجابة.
