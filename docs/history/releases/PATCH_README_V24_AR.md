# v24 — Host Answer Lock (إغلاق إجابة الهوست)

**متطلبات التثبيت:** التعديلات في هذا الملف مخصصة لنسخة v23 (Scoreboard Polish).

ضع محتويات `ta7adyelgeel_host_answer_lock_v24_PATCH_ONLY.zip` في المجلد الرئيسي للمشروع، مع استبدال الملفات ذات المسارات المتطابقة، ودون حذف ملفات أخرى.

### ما الذي تغير؟
- عند قبول أول إجابة من الهوست، يختفي نموذج الإجابة الذي فوق رأسه فوراً.
- لا يمكن إعادة فتح النموذج لتعديل الإجابة في السؤال نفسه، حتى بعد إعادة تركيب الـReact component أو تغيير Twitch ID.
- إذا أجاب الستريمر أولاً من شات Twitch، يقفل نموذج الهوست أيضاً.
- عند بدء سؤال جديد، يصبح الإدخال متاحاً مجدداً.
- لم تتغير تصميمات الأزرار أو CSS أو منطق النقاط؛ وبالنسبة للإجابات متعددة الخيارات يظل أول اختيار مقبول من الشات هو المعتمد.

### التحقق
- `npm install` إن كانت Dependencies غير مثبتة.
- `npm test` لاختبارات Vitest بما فيها الاختبارات الجديدة لـv24.
- للتجربة: إجابة `!1` من الهوست، ثم محاولة `!2` في نفس السؤال يجب رفضها. انتقلي لسؤال جديد ويجب ظهور واجهة الإجابة من جديد.

ملحوظة: اختبار Electron على Windows لا يمكن اعتباره مكتملاً بناءً على اختبارات الكود فقط.
