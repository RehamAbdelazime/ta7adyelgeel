# ترقية V42 → V43 | محتوى اعرف الفيلم واعرف النجم

1. ضعي محتوى هذا الـPATCH فوق مشروع V42 مع الدمج والنسخ؛ **V43 لا تحذف أي ملف من V42**.
2. أضيفت 30 رسمة SVG أصلية لألغاز الأفلام (تعمل Offline).
3. أُضيفت سجلات 20 صورة حقيقية لنجوم من Wikimedia Commons مع توثيق حقوق كل صورة، **لكن صور النجوم نفسها ليست ضمن الـZIP**.
4. على الجهاز المتصل بالإنترنت شغّلي `npm run visuals:cache` للحصول على الـ20 صورة في مجلد الأصول. تأكدي أن الأمر طبع 20 نجاحًا أو already cached. دون ذلك، التطبيق يعتمد على Commons وقت اللعب وقد تظهر رسالة خطأ للصور إن انقطع الاتصال.
5. افحصي `npm run verify:visual-content-v43` وجرّبي القص/الأنيميشن في Electron؛ لم يتم التحقق بصريًا على الأجهزة الحقيقية بعد.
6. الملحق `docs/V43_VISUAL_MEDIA_ATTRIBUTION.csv` يحتوي مصادر الصور ورخصها وأسماء أصحابها؛ احتفظي به عند نشر اللعبة.
7. **تنبيه:** صور الأفلام ليست بوسترات أو لقطات رسمية بل رسومات استدلالية أصلية. استخدام بوسترات ومشاهد أصلية يحتاج تراخيص منفصلة.

لا تغيير مقصود في XP أو الـSpectators أو Chaos أو التقدم السابق.
