# Ta7ady ElGeel — Windows QA portability fix 4 (V45)

الأساس: V45 QA StrictMode Fix 3. يصلح أسباب فشل اختبارات Windows بناءً على اللوجات الحقيقية التي وصلت من جهاز المستخدم.

## ما تم إصلاحه

1. عدد من سكريبتات التحقق كانت تعتمد على `require('/opt/nvm/versions/node/v22.16.0/lib/node_modules/typescript')`، وهو مسار Linux لا يوجد على Windows؛ فشل 12 من 55 اختبار Regression وبسببه توقف `npm test` و`npm run build` مبكرًا. تم استبدال جميع المراجع (17 ملف سكريبت) بـ `require('typescript')` الذي يستخدم مكتبة TypeScript المثبتة داخل المشروع عن طريق `npm ci`.
2. بعد اختبار 500 بوت، اختبار Late Spectators كان يستدعي `addBots(5)` رغم حد 500 بوت، فيفشل الاختبار دائمًا لعدم إضافة أي مشاهد. الآن يحاكي خمس رسائل `!join` من حسابات QA جديدة ومختلفة عبر مسار Twitch الحقيقي، ويقارن زيادة عدد Spectators قبل/بعد. لم يتم تغيير قاعدة 500 بوت في لوحة التحكم.
3. أضيف فحص آلي يمنع رجوع مسارات Linux داخل سكريبتات الاختبار، مع تقرير QA منفصل عند تخطي اختبار Electron نتيجة فشل Build السابق، بدل احتساب فشل تابع على أنه خلل مستقل في Electron.

## التشغيل

- **الأفضل:** فك النسخة الكاملة V45 QA Fix4 في فولدر جديد؛ نفّذ `npm ci`، ثم شغّل `RUN_FULL_QA_WINDOWS.bat`.
- **عند استخدام PATCH:** انسخ الملفات فوق نسخة **QA StrictMode Fix 3**، ثم شغّل ملف BAT نفسه. لا تحذف `node_modules` أو ملفاتك الشخصية.
- عند ظهور مشكلة، استخدم `qa-artifacts/qa-full-report.json` وملفات `qa-step-*.log` ومعرض الصور `qa-artifacts/ui-latest/index.html`.

## تحقق محلي في بيئة الإصلاح

- اختبارات Source Regression: 56/56 ناجحة.
- اختبارات QA الأساسية: 71/71 ناجحة.
- فحص صياغة JavaScript/Node للملفات المعدلة: ناجح.
- الاختبارات الكاملة داخل Windows / Electron والـChromium UI ما زالت تحتاج تشغيلًا على جهاز المستخدم؛ لا توجد شهادة نجاح لها قبل ذلك.

## مشاكل موجودة في لوجات Windows خارج هذا الإصلاح

- صور الفيلم التي تعتمد على بعض روابط elcinema.com وyoum7.com تمنعها سياسة Content Security Policy؛ مطلوب صور محلية مصرح باستخدامها وعدم الاعتماد على hotlinks.
- رسائل React عن خلط اختصارات CSS مثل background مع backgroundImage تظهر بكثافة وتحتاج مراجعة منفصلة.
- تدقيق الصور وجد 14 سؤالًا بلا صور صالحة، و23 سؤالًا بصور remote-only، وحقوق الاستخدام غير محسومة. إصدار البث ليس جاهزًا.
- معرض لقطات الشاشة لم يرفق في هذه الجولة؛ لن ندعي إجراء مراجعة بصرية بشرية للـ232 Screenshot بدون الصور الفعلية.
