# Ta7ady ElGeel — Event-Driven Stage Lighting v22

التحديث مبني **مباشرةً** على `scoreboard_lighting_v21`، وموجّه لنسخة الكمبيوتر (Electron).

## الجديد

- عند بداية كشف الإجابة الصحيحة في مرحلة `scoring`، يوجّه كشافا جانبي المسرح ضوءهما نحو مركز حارة الإجابة الصحيحة، وفق **نفس** إحداثيات `ANSWER_STAGE_LAYOUT` المستخدمة لحركة الجمهور. الشعاع والبقعة الأرضية يدوران معًا حول موضع اللمبة؛ ليست بقعة منفصلة عشوائية.
- بعد 4.8 ثوانٍ — وهي مدة إظهار الحل نفسها في الـGameplayOverlay — ينتقل المشهد إلى إضاءة تكريم المتصدر إذا كان هناك لاعب رسمي حصل على نقاط فعلًا.
- في النتائج النهائية أيضًا تظهر إضاءة علوية دافئة قصيرة من موقع منتصف الـTruss، ويظهر لمعان ذهبي هادئ **خلف** بطاقة المتصدر، مع بقاء الأزرار قابلة للضغط.
- إنهاء الجولة من Settings، أو عدم وجود نقاط إيجابية، **لا** يطلق احتفالًا زائفًا. وباقي مراحل اللعب تحتفظ بإضاءة v21 الخفيفة المتحركة.
- إضاءة النجاح خضراء نعناعية خفيفة للإشارة إلى صحة الحل؛ الذهب فقط لتكريم المتصدر. بقية المسرح تحافظ على Cyan/Pink.
- لا تُستخدم صور جديدة أو `requestAnimationFrame` أو مؤقتات حركة مستمرة؛ CSS + SVG وعلامة مرحلة واحدة فقط بعد الكشف.
- عند تفعيل Reduced Motion، يتوقف تحريك الأشعة والتكبير ويظل اللون ثابتًا.

## البنية

- `src/ui-react/components/visual/mini-game-lighting-cues.ts` — قواعد المرحلة وإحداثيات استهداف الحارات.
- `src/ui-react/components/visual/MiniGameLightingRig.tsx` — أشعة مصدرها كشافات المسرح الفعلية، مع بقعة أرضية مرتبطة بالشعاع.
- `src/ui-react/components/visual/VisualWorldLayer.tsx` — ربط الإضاءة بحالة السؤال والنتائج.
- `src/ui-react/components/gameplay/scoreboard/ScoreboardAmbientLights.tsx` + `Scoreboard.tsx` — لمعان النتيجة المشروط بالنقاط والصفحة الأولى.
- `src/ui-react/styles/event-stage-lighting-v22.css` — الـAnimations والـReduced Motion؛ مستورد بعد ملف v21.
- `scripts/verify-event-lighting-v22.mjs` — 43 فحصًا للمرحلة والإحداثيات وتكامل الملفات.

## التجربة المطلوبة على Windows

1. اختاري Food Origin أو Maze Gates، وأجيبي عن أحد الخيارات.
2. وقت كشف الحل، راقبي حركة كشافات الجانبين باتجاه حارة الإجابة الصحيحة، ومطابقتها للأرقام 1–4.
3. بعد شاشة الحل، راقبي لمعان المتصدر القصير في الـScoreboard إذا كانت النقاط > 0.
4. اختبري End Mini Game من Settings: لا ينبغي ظهور احتفال فائز بمجرد الإنهاء.
5. جرّبي 1280×720 و1920×1080، وبعدد جمهور كبير، ومع Reduced Motion.
