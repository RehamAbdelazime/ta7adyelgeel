# Ta7ady ElGeel — Lucky Cup V28 / إصلاح العرض والهوست

الأساس: **ta7adyelgeel_lucky_cup_v27_SOURCE.zip** (ليس أي إصدار أقدم).

## ما تم إصلاحه

1. **اختفاء الكوبايات في بداية الجولة:** المرحلة `tour_starting` كانت تستخدم `display:grid; align-content:center` من كارت العدّ التمهيدي القديم؛ لذلك كان الـQuestion Shell ينكمش وسط الشاشة ويختفي الـPlayfield. أُضيف CSS محلي يفرض نفس ارتفاع وعرض مرحلة الإجابة باستخدام `display:block` و`grid-template-rows: auto minmax(0,1fr) auto`.
2. **الكرة:** تظهر الكرة الذهبية بوضوح أسفل كوباية مرفوعة عند بدء الجولة، ويستمر العرض الواضح لمدة **1.8 ثانية** بدل 0.95 ثانية. بعدها تنخفض الكوباية وتختفي الكرة *قبل التبديل*، ثم تتحرك 3 كوبايات وفق خطة التبديلات الحتمية، وتُكشف الكرة مجددًا عند النتيجة مع رفع الكوباية لمسافة مناسبة. الكرة مخفية أثناء حركة التبديل ومرحلة اختيار الإجابة.
3. **توضيح المرحلة:** إرشاد موجز داخل مساحة اللعب يتغير من «بص كويس» إلى «ركز في حركة الكوبايات» ثم «الكورة تحت أنهي كوباية؟».
4. **إجابة الهوست:** تصميم Pod أوضح وأكبر قليلاً، أعلى ويسار المسرح بعيدًا عن وجه الهوست ومربعات الجمهور. نفس حراسة الإجابة السرية وعدم قبول إجابتين، بدون تغيير قواعد التقييم أو المنطق.
5. **مكونات معزولة:** الإضافات الجديدة في `lucky-cup-v28.css` و`host-answer-pod-v28.css` بدل التعديل العشوائي على CSS الألعاب الأخرى.
6. **ملف V25 المفقود:** موجود في مصدر V28 الكامل. لا تحذف الـimport منه.

## تركيب الملفات

- **SOURCE (الموصى به):** فك ضغط `ta7adyelgeel_lucky_cup_v28_SOURCE.zip` كنسخة المشروع الكاملة. احتفظ بنسخة احتياطية من المشروع المحلي أولًا، خصوصًا أي تعديلات محلية بعد V27.
- **PATCH:** إذا كنت تعمل على V27 بالضبط، فك `ta7adyelgeel_lucky_cup_v28_PATCH_ONLY.zip` فوق فولدر المشروع واسمح باستبدال الملفات المذكورة في الـPatch.
- لا تطبق PATCH على إصدار قديم مثل V23 أو V25.
- شغّل المشروع كالمعتاد بـ `npm run dev` بعد تثبيت الاعتماديات (إذا كانت غير مثبتة).

## التحقق

- `node scripts/verify-lucky-cup-v27.cjs`: نجح 26,918 فحص للحركة والمنطق والتزامن عبر 840 خطة.
- `node scripts/verify-lucky-cup-v28.cjs`: نجحت فحوص ربط CSS والأصول وTypeScript syntax.
- `node scripts/verify-css-modules.mjs` و`verify-shared-choices-v25.mjs` و`verify-event-lighting-v22.mjs`: نجحت.
- **لم أتمكن من إجراء اختبار واجهة Electron أو build كامل** هنا؛ تعذّر تثبيت npm dependencies، ومتصفح Chromium المحلي منع فتح صفحة المعاينة بسياسة البيئة. الاختبار البصري داخل تطبيق Windows ما زال مطلوبًا.

## اختبار يدوي مهم

1. اختر Lucky Cup واضغط بدء الجولة. يجب أن يظهر المسرح بحجمه الكامل والكوبايات الثلاث من **أول فريم**، مع كرة واضحة تحت كوباية مرفوعة.
2. راقب اختفاء الكرة ونزول الكوباية، ثم التبديلات الخمسة/الثمانية/الاثني عشر حسب الجولة.
3. عند فتح الإجابات، يجب إخفاء الكرة وظهور خيارات شمال/وسط/يمين، وظهور Pod الهوست **فوقه إلى اليسار** وليس فوق الجمهور أو ملاصقًا لإجابات الشاشة.
4. عند انتهاء الإجابات، ترتفع الكوباية الصحيحة وتظهر الكرة بوضوح. قارن مكان الكرة مع التبديلات التي رأيتها.
5. كرّر على 1280×720 وعلى دقة شاشة البث، ثم جرّب Pause/Resume والجولات الثلاث.
