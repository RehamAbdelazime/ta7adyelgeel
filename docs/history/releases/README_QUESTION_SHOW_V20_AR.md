# Ta7ady ElGeel — Question Show v20

تحديث تجريبي لتصميم السؤال المسرحي بناءً على قرارات واجهة اللعب المعتمدة.

## التنفيذ

- **شاشتا Food Origin وMaze Gates** تستخدمان `QuestionScreenShell` الموحّد بنسخة v20. بقية الميني جيمز تظل مؤقتًا على التخطيط القديم حتى مراجعتها؛ لم نغير قواعد الألعاب أو النقاط.
- أعلى لوحة السؤال: بانر واحد مدمج لاسم الميني جيم ورقم السؤال، يليه Timer أفقي بعرض اللوحة وسؤال كبير وواضح.
- محتوى التحدي يشغل أكبر منطقة متاحة. صورة Food Origin لا تُقص؛ يُعرض محيطها بمؤثر خلفية ناعم كي لا تظهر مساحات سوداء جانبية كبيرة.
- الخيارات في صف أفقي واحد بالترتيب المرئي **1 / 2 / 3 / 4 من اليسار لليمين** حتى مع العربية. ترتيب الكلمات أو الدول داخل الخيارات لا يتغير، وبالتالي لا نفصل ما يراه اللاعب عن أوامر Twitch.
- فقاعة إجابة الهوست نقلت إلى **أعلى رأس الهوست على طرف المسرح** بدل HUD السؤال. لا يظهر الحقل أثناء نتيجة السؤال.
- أرضية الجمهور تستخدم 4 حارات طولية هادئة بدل الدوائر؛ رقم كل حارة عند بداية الأرضية تحت الشاشة. الإضاءة خفيفة بلون Cyan موحد قبل النتيجة.
- عند كشف الحل تضيء الإجابة والحارة الصحيحة باللون الأخضر مع تخفيف الباقي، وتظل الشخصيات في الحارات أثناء عرض النتيجة ثم تعود إلى الأجنحة.
- `ANSWER_STAGE_LAYOUT` هو مصدر إحداثيات الحارات والحركة نفسه؛ يوجد اختبار للأماكن من 1 إلى 72 لاعبًا في الحارة، لكن الاختبار البصري داخل Windows مع جمهور كبير ما زال مطلوبًا.

## تشغيل وتحقق

1. افتح المشروع في مجلد منفصل.
2. `npm install` أو `npm ci` لإكمال التبعيات، ثم `npm run dev`.
3. `npm run verify:question-zones` للتحقق من توافق المكونات وسمات التصميم.
4. `npm test` و `npm run build` للتأكد من التشغيل الكامل بعد تثبيت التبعيات.
5. جرّب Food Origin بالعربي والإنجليزي، سؤال جارٍ، كشف الإجابة، الإجابة من الهوست، دخول عدة لاعبين وتغيير التوقيت.
6. جرّب Maze Gates، ثم تأكد من أن الـScoreboard وشاشات الألعاب القديمة ما زالت تعمل كما كانت.

**ملاحظة خصوصية:** حقل الهوست يستخدم `type=password` لإخفاء الرقم أثناء كتابته، لكن الفقاعة نفسها مرئية ضمن نافذة اللعبة وقد يراها جمهور OBS إن تم التقاط النافذة. لو إجابة الهوست يجب أن تكون سرية تمامًا، استخدم أداة إدخال منفصلة عن مصدر OBS.

**حالة التحقق:** اجتازت الشيفرة فحوص v20 البنيوية 17/17، v19 26/26، فحص CSS/الأصول، والأمان 24/24، وفحوص transpilation للملفات المعدلة. اختبار حساب المواضع نفّذ 1064 حالة. لم يكتمل TypeScript build النهائي ولا تجربة Electron المباشرة بسبب غياب تبعيات Vite في بيئة إعداد النسخة؛ المعاينات الصور محاكاة HTML/CSS وليست لقطات من Electron.
