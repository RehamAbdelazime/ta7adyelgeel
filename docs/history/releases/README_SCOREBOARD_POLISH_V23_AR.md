# Ta7ady ElGeel — Scoreboard Polish v23

تحديث مُطبّق **فوق v22**، خاص بشاشات **نتيجة الجولة، النتائج النهائية، والنتائج بين ألعاب الجولة**. لا يغير منطق جمع النقاط أو Twitch أو مؤثرات الإضاءة المرتبطة بالنتيجة.

## مشاكل الواجهة التي تمت معالجتها

1. عنوان النتيجة الكبير منفصل عن معلومات الجولة واللعبة: أصبح بانر مقسم بنفس بنية بانر السؤال (`اسم اللعبة | ✦ نتيجة الجولة 1/3 ✦`). في النتيجة النهائية يظهر `تحدي الجيل | ✦ لوحة النتائج ✦`، وفي إنهاء الجلسة مبكرًا يظهر عنوان إنهاء الجلسة مع التقدم المنفّذ.
2. عبارات `اللاعب 1` و`جولة 1/3` المتناثرة أعلى اللوحة: أزيلت من الشاشة؛ رقم الجولة يظهر **مرة واحدة فقط داخل البانر**.
3. شرائح `ج1 0`, `ج2 0` الصغيرة بجوار اسم المتصدر: أُخفيت بصريًا مع إبقاء البيانات الأصلية متاحة لقارئ الشاشة، ولم تُحذف بيانات الجولات أو حساباتها.
4. مساحة الجدول الضخمة عند وجود لاعب واحد: بطاقة النتيجة أصبحت متوسطة العرض ومتمركزة في مساحة العرض. تظهر بطاقات الترتيب في عمودين عند وجود لاعبين آخرين.
5. زر `التالي` و`العودة للمسرح`: نفس `ScoreboardPrimaryAction` المستخدم في كل مراحل النتائج، بتصميم Cyan بسيط وزوايا 8px من لغة اللعبة. حُذف السهم الدائري لأنه عنصر شكلي زائد وموضعه يتعارض مع RTL؛ الأزرار الآن ذات تسمية مباشرة، **متمركزة في أسفل النافذة** بالعربي والإنجليزي.
6. الحفاظ على إضاءات المسرح v22، مع تخفيف سطوع إضاءات *داخل* لوحة النتائج لتفادي منافسة النصوص.

## البنية

- `src/ui-react/components/gameplay/scoreboard/Scoreboard.tsx`: بانر واحد مشترك `ScoreboardHero` لنتيجة الجولة والنهائية وبين الجولات. نفس بيانات النقاط والصفحات القديمة.
- `src/ui-react/components/gameplay/scoreboard/ScoreboardPrimaryAction.tsx`: الزر المشترك بلا سهم إضافي.
- `src/ui-react/styles/scoreboard-casual-v23.css`: الـCSS الخاص بالتغييرات؛ مُستورد **بعد** CSS v22.
- `scripts/verify-scoreboard-casual-v23.mjs`: فحوص بنيوية إضافية؛ التشغيل: `npm run verify:scoreboard-v23`.

## حدود التحقق

نجحت مراجعات البنية 16/16 واختبارات Game Show السابقة 26/26، وEvent Lighting 43/43، وفحوص الأمان 24/24. تمت مراجعة المعاينة البصرية على 1280×720 و1650×928، بالعربي والإنجليزي، وبحالة لاعب واحد و8 لاعبين، وتأكدنا من إمكانية الضغط على CTA داخل Chromium.

**المعاينات غير مصورة من Electron نفسه.** لم يكتمل `npm run typecheck` في بيئة التسليم بسبب عدم وجود `vite/client` محليًا. يلزم اختبار Windows بعد تثبيت التبعيات، وبخاصة التنقل بعد End Mini Game وأحجام الخط الفعلية.

## تطبيق الـPatch

1. خذي نسخة احتياطية من **v22**.
2. فكّي محتويات `ta7adyelgeel_scoreboard_polish_v23_PATCH_ONLY.zip` على جذر مشروع v22 مع السماح باستبدال الملفات الموجودة.
3. شغّلي `npm run verify:scoreboard-v23` ثم `npm run dev`.
4. اختبري Round Score + Final Score + End Mini Game، وباللغتين.
