# Ta7ady ElGeel — v25: Shared Choice Questions + Lobby Copy

النسخة الأساسية: **Host Answer Lock v24**. التعديل ده لا يغير scoring أو Twitch commands أو أرقام الاختيارات.

## واجهة اللوبي
- تغيير ترجمة `ui.landing.playersJoined` من «اللاعبون المنضمون» إلى **«هيلعبوا معانا»**.
- إزالة حالة الشات الفارغة «جاهزين للشات!» والكرة المضيئة والنص أسفلها. عند وصول رسائل حقيقية تظهر كما هي؛ حالة الاتصال تظل موجودة في الهيدر.

## شاشات الأسئلة
كان `QuestionScreenShell` مشتركًا، لكن التصميم الحديث كان **opt-in** في Food Origin وMaze Gates فقط؛ لذلك شاشة عد الأشكال فضلت تستخدم التخطيط القديم. في v25 تم:
- تفعيل `layout="choice"` في **Shape Count**: نفس البانر، المؤقت بعرض الشاشة، مكان السؤال، اختيارات أسفل التحدي، والعداد.
- إظهار 3 أشكال كاختيارات **أفقية** (اللعبة بها 3 اختيارات في الجولة المعروضة)، مع الحفاظ على ألوان رسومات الأشكال نفسها وتوحيد حدود الكروت Cyan.
- استخدام نفس التصميم في **Guess Logo** و**Couple or Siblings** و**True/Fake**؛ بقيت Food Origin تستخدمه كما سبق، وMaze Gates تستخدم النسخة التفاعلية منه.
- توحيد قرار الشاشات الحديثة في `modern-question-games.ts` لاستخدامه من أربعة أماكن: `App` لإخفاء إجابة الهوست القديمة، `HostMascotLayer` لإظهار الفقاعة فوق رأس الهوست، `GameplayOverlay` لإزالة الشريط الزائد، و`CitizenPlaza` لإبقاء الجمهور أثناء كشف الإجابة.
- تقييد قواعد الأشكال الجديدة داخل ملف CSS مستقل، من غير تعديل CSS الألعاب القديمة أو منطق النتائج.

## ما زال يحتاج نقلًا بصريًا منفصلًا
Memory Count، Before or After، Count the Beat، Hangman، Lucky Cup. كلهم يستخدموا `QuestionScreenShell` بالفعل، لكن لهم محتوى/تفاعل خاص ما زال يستخدم Layout legacy. لا يتم نقلهم عشوائيًا قبل مراجعة السلوك والواجهة. الـScoreboard مشترك ولم يتغير في التحديث ده.

## التشغيل والتحقق
1. استخدم نسخة v24 كأساس، وطبّق PATCH v25 بنفس مسارات الملفات.
2. من جذر المشروع: `npm install` (لو التبعيات غير مثبتة) ثم `npm run dev`.
3. فحوص سريعة: `npm run verify:shared-choices-v25` و`npm run verify:localization-contract`.
4. اختبر في Windows: Main Screen بالعربي (ترجمة العدد والشات الفارغ)، Shape Count قبل/أثناء/بعد الإجابة، اختيارات !1/!2/!3، فقاعة الهوست، وأماكن الجمهور؛ ثم جرّب Guess Logo وTrue/Fake وCouple/Siblings.

**الاختبار المرئي داخل Electron والبناء الكامل لم يكتملا في بيئة العمل هنا.** اختبارات التحقق البنيوي وفحوص TypeScript parsing ليست بديلًا عن تشغيل اللعبة.
