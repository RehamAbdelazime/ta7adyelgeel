# Ta7ady ElGeel — Bilingual Typography v11

هذه حزمة تعديل فوق **Casual Settings v10**، لا تُطبَّق فوق v8 أو v9 مباشرة.

## القرار الفني

- **Fredoka Variable** لواجهة اللعبة الإنجليزية: عناوين مرحة بدون طابع Hardcore، أزرار، شات، اختيار الألعاب، وشاشات الأسئلة.
- **Alexandria Variable** للنصوص العربية: خطوط أنظف وأوزان متعددة ومسافات مناسبة للحروف العربية. إن ظهر اسم Twitch لاتيني والواجهة عربية، يُعرض الاسم اللاتيني بـFredoka والكتابة العربية بـAlexandria وفق دعم الحروف.
- **لوجو اللعبة المرسوم:** لم يتم تعديله. خط Labo القديم موجود في النسخة الأصلية لكنه لم يعد مفروضًا على كل عناصر React. الهدف تقليل التشويش البصري.
- الألوان والمسرح والـSpotlights وحركة الهوست وتوقيتات الألعاب لم تتغير.

## التعديلات

- تحميل الخطين من `@fontsource-variable` بواسطة Vite، ما يضعهما ضمن ملفات التطبيق عند بناء Electron، بلا اتصال إنترنت وقت اللعب.
- إنشاء ملف `typography-system-v11.css` في آخر ترتيب الـCSS لتصحيح تجاوزات قواعد `!important` القديمة.
- ضبط العناوين والأزرار الرئيسية في Lobby، وعدّاد اللاعبين، الشات، أسماء المشاركين، شاشة Mini Game/Tour، شاشة اختيار الميني جيم، وSettings v10.
- إصلاح مسافات الحروف الإنجليزية الزائدة، وإيقاف letter-spacing على العناصر العربية، وضبط ارتفاعات الأسطر العربية.
- تحسين ظهور عنوان الكارت ونص زر الاختيار بحيث يدعم سطرين دون ضغط.
- إضافة `lang` إلى جذري واجهة اللعبة وتسجيل الدخول، مرتبط مباشرة باللغة المختارة داخل اللعبة.
- إضافة أمر تحقق مستقل: `npm run verify:typography`.

## التثبيت على المشروع الأصلي

1. اعملي نسخة احتياطية من المشروع الحالي v10.
2. انسخي محتويات الـPatch فوق جذر المشروع، مع استبدال الملفات الموجودة.
3. من مجلد المشروع نفذي `npm install` لتنزيل حزمتَي الخطوط وتحديث بقية التبعيات الناقصة إن وجدت.
4. شغّلي `npm run verify:typography` ثم `npm run build` ثم `npm run dev`.

**مهم:** لا تتطلب اللعبة الإنترنت لتحميل الخطوط بعد عملية `npm install` والبناء. أصول الخطوط نفسها ليست داخل ملف الـPatch؛ مدير حزم npm هو الذي يوفّرها بتراخيصها الرسمية.

## قائمة المراجعة بعد التشغيل

- الإنجليزية والعربية: Lobby وPlay/Settings على خط منتصف موحد.
- الإنجليزية والعربية: شاشة `WHAT ARE WE PLAYING?` / `هنلعب إيه؟`، بطاقتا Mini Game/Tour وعناوينهما وأزرارهما دون تداخل.
- Settings العربية والإنجليزية، خاصة أزرار خيارات الشاشة والأرقام وأسماء Twitch.
- Chat: رسالة عربية، رسالة إنجليزية، اسم مختلط، اسم طويل.
- Game Grid والأسئلة والنتائج؛ جرّبي النصوص الطويلة بشكل خاص.
- اختبري 1280×720 و1920×1080 داخل Electron والـOBS.

## التحقق المنجز والقيود

- نجحت فحوص ترتيب CSS، وأصول الشخصيات، وتكامل الخطوط، وفحوص المشهد، وفحوص الأمان (24/24).
- فحص CSS بمُحلّل قواعد مستقل، بالإضافة لاختبار حساب خصائص نمط عربي في Chromium (باستخدام الخط الاحتياطي نظرًا لغياب حزم الخطوط من بيئة الاختبار).
- **لم يتم عمل Build فعلي بعد إضافة حزمتَي الخطوط** لأن بيئة التنفيذ لا تصل إلى سجل npm، وبيئة dependencies المتاحة بها ملفات ناقصة. لذلك لا أضمن عدم وجود فروق طفيفة في المقاسات عند تشغيل الخطين الحقيقيين. اختبار Windows مطلوب قبل اعتماد النسخة النهائية.
