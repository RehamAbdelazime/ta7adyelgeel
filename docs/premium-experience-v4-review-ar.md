# Ta7ady ElGeel — Premium Experience v4 (تحديث الشاشة الأولى)

**الأساس:** Full Cleanup v3 SOURCE. هذه نسخة تطوير للكود وليست إصدار EXE جاهزًا للنشر.

## تغييرات تم تنفيذها

1. **شاشة المسرح (LED):** إطار خارجي متدرج خفيف يربط النصف الخاص باللوجو والنصف الخاص بالشات، وتحسين عمق الأسطح والحواف، من غير إضافة لوحات مزخرفة تشوش على المحتوى.
2. **واجهة اللوجو والتفاعل:** إضاءة مركزة هادئة خلف العلامة، رفع التباين بين PLAY وSETTINGS، وإبقاء Settings ثانويًا مع دعم focus مرئي للكيبورد.
3. **مؤشر المشاركين:** `PLAYERS JOINED 01` داخل اللوحة الرئيسية يتحدث مباشرة من `snapshot.citizens.length`، مع ترجمة عربية وإنجليزية وإعلان مناسب لقارئ الشاشة. العد يشمل المشاركين الرسميين والمتفرجين المدرجين في `citizens`.
4. **أماكن الجمهور:** تعديل الحساب الرياضي للمواضع في `citizen-helpers.ts`: ثمانية أعمدة × تسعة صفوف بترتيب ثابت يبدأ من الوسط، بدل بداية الصف الأمامي المنخفضة جدًا. كل المراكز الأفقية في نطاق 10%-90% والرأسية في نطاق 10%-50% من طبقة الجمهور. كل المواضع الـ72 مختلفة ولا تعيد ترتيب الموجودين عند انضمام جديد.
5. **أحجام الجمهور والـNameplates:** شخصيات أكبر قليلًا عندما يكون الحضور قليلًا، مساحة ووضوح أفضل للاسم، لوحات مختصرة تدريجيًا مع زيادة الكثافة بدل تداخل الاسم الكامل، وإضاءة دخول مؤقتة.
6. **حركة الهوست:** رد فعل بسيط على دخول لاعب أو الضغط على Play، عن طريق تحريك العنصر الحاوي *فقط* من غير استبدال صورة الوجه/الأذرع أو عمل Cross-fade بين صورتين مختلفتين.
7. **حركة الواجهات:** انتقال ظهور قصير لخطوات الاختيار، مع احترام إعداد نظام التشغيل `prefers-reduced-motion`.
8. **Live Chat:** تحسين بسيط لخامة الخلفية والتفريق بين الرسائل مع الإبقاء على اتصال Twitch وآلية التمرير والأحداث دون تغيير.
9. **تنظيم الكود:** الإضافات البصرية في `src/ui-react/styles/premium-experience.css` منفصل ويُستورد **بعد** ملفات v3. لا تعديل لقواعد اللعب أو النقاط أو عدد الميني جيمز.

## فحوص تم تنفيذها

- `npm run verify:cleanup` **نجح**، ويتضمن تحقق v4 الجديد.
- Verified gameplay registry: **11 مسجلًا، 8 متاحة**.
- Scoring policy, mode picker, landing identity, assets and sprite alias checks **نجحت**.
- Security audit: **24/24**.
- Parse-only: **119 ملف TS/TSX** دون أخطاء صياغة؛ فحص CSS الجديد والملفات Premium دون أخطاء Parse.
- Visual CSS/DOM fixture: محاكاة *ساكنة* باستخدام بنية عناصر مطابقة وملفات CSS والخلفية الأصلية، على دقات **1280×720، 1650×928، 1920×1080، 2560×1440**. في هذه المحاكاة، اللاعب لا يتجاوز الحافة السفلية، واسم اللاعب ظاهر، واللوحتان داخل نطاق الشاشة. **هذه ليست لقطة من React أو Electron**، وخط Labo قد لا يُحمّل في المحاكاة لقيود المتصفح.

### حدود التحقق

تعذر `npm ci` الكامل بسبب عدم توفر حزم في الـoffline cache وبطء الاتصال بمستودع الحزم؛ لهذا تعذر Build نهائي وتشغيل Electron مع Twitch حي. فحوص التحقق البنيوية ليست بديلًا عن اختبارات التطبيق الحقيقية. لا تُعتمد النسخة للإطلاق قبل فتحها على Windows وفحص 720p و1080p وعدة لاعبين والشات.
